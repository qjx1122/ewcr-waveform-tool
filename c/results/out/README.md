# Codec input/output files

Generated by `make test` and `make test-data`. Re-run those commands to refresh.

For each case `<stem>`:

| file | meaning |
| --- | --- |
| `<stem>_original.csv` | original waveform |
| `<stem>_reconstructed.csv` | waveform after decode |
| `<stem>_compare.csv` | original, reconstructed, error |
| `<stem>_compressed.ewcr` | compressed bitstream (magic `EWCR`) |

Field-data index: `manifest.csv`.

`.ewcr` layout (little-endian):

```
"EWCR" (4) | version u8=1 | algo_id u8 (1=ASBC 2=DWT 3=CS-OMP 4=MMC 5=SVDCS)
| pad u8×2 | N u32 | fs f64 | f0 f64 | bits_compressed f64
| codec-specific payload
```
